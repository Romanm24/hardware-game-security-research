## Image Guidelines

All images added to this directory should:

- Be captured from the isolated lab environment only (no production systems, no live game servers)
- Be annotated to highlight security-relevant observations
- Include a brief caption describing what is shown and its defensive significance
- Redact any sensitive information (serial numbers, account identifiers, network addresses)
- Be accompanied by an entry in this README describing the content
